# 国内社会热点公众号流程

定位：国内社会生活热点，每天六篇，每篇 1000 字左右，推送到飞书。选题偏消费、健康、家庭、养老、城市服务、传统生活和中年读者更容易有共鸣的话题。

硬规则：

- 不生成 AI 图片
- 微信接口需要封面素材，因此只上传纯白占位图，并设置 `show_cover_pic=0`
- 避开政治、时政、国际、军事、敏感案件、灾难伤亡、未成年人隐私等高风险内容
- 文章只做生活观察、消费提醒、职场启发、情绪共鸣和实用建议
